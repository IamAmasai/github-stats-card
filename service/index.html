Ansai · Self-hosted stats

The GitHub card that counts
the private work too.

Public stats cards only see public repositories. Most of the real work — client systems, company infrastructure, the platform itself — lives in private repos, so the public grade undersells the engineer. This service reads the full record with a server-side token and renders one honest card: every commit, every pull request, public and private.

What it counts

All-time commits and pull requests across personal and organisation repos (private included), contributions for the last year, the current streak, language volume, and a grade computed with the standard ranking formula — run on the full data instead of the public slice.

How it works

One serverless function. It calls the GitHub GraphQL and search APIs with a token that never leaves the server, computes the numbers, and returns an SVG. The CDN caches it for six hours, so the card stays fast and the API stays quiet.

Use it

The card is a plain image URL — it embeds anywhere Markdown or HTML renders images, starting with a GitHub profile README.
